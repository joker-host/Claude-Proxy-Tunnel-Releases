# 🛡️ Claude-Proxy-Tunnel

**Claude Code и Claude Desktop через ваш прокси — там, где Anthropic API недоступен напрямую**

Весь трафик Claude идёт через купленный вами зарубежный прокси, а остальной
интернет работает как обычно. Программа всё настраивает сама.

## 💡 Зачем это нужно

Anthropic API (`api.anthropic.com`) не отвечает на запросы из некоторых стран
(в том числе из России). Обычное решение — пустить трафик Claude через
зарубежный прокси. Но вручную это неудобно и хрупко:

- **Claude Desktop и VS Code** не умеют работать с прокси, где нужен логин и
  пароль — показывают окно авторизации или просто молчат.
- **Длинные ответы Claude** (фаза «размышления», минуты тишины) обрываются с
  ошибкой `socket connection was closed unexpectedly`.
- После перезагрузки компьютера настройка слетает, и Claude перестаёт работать.

Claude-Proxy-Tunnel решает всё это за пару минут и держит настройку рабочей.

---

## ✨ Что умеет

| Возможность | Что делает |
|---|---|
| 🌉 **Локальный мост** | Принимает запросы Claude и подставляет логин/пароль вашего прокси автоматически — приложениям не нужно ничего знать про авторизацию |
| 🔌 **HTTP и SOCKS5** | Понимает оба типа прокси; тип определяется **автоматически** при вводе строки |
| ⚡ **Без лишней задержки** | Оптимизация соединения (TCP_NODELAY + keep-alive): запросы идут быстро, длинные ответы не рвутся |
| 🔁 **Работает после перезагрузки** | Мост и переменные окружения восстанавливаются при входе в систему сами — Claude работает сразу |
| 🟢 **Статус в трее** | Зелёный (всё работает) / жёлтый (нужно внимание) / красный (мост остановлен) |
| ⬆️ **Обновление из приложения** | Настройки → Обновления → одна кнопка скачает и поставит новую версию |
| 🧹 **Чистое удаление** | Встроенный мастер удаления убирает всё, что поставила программа, с галочками для сопутствующих компонентов |
| 🛡️ **Защита брандмауэром** | *(только Windows)* мост может ходить **только** на ваш прокси и никуда больше — на уровне ОС |

## 🧭 Как это работает

```
┌─────────────────────────┐                  ┌─────────────────────────┐
│  Claude Code (VS Code)  │   локально, без  │  Мост на 127.0.0.1:8889 │
│  Claude Code в терминале │  ───────────────▶│  подставляет логин/     │
│  Claude Desktop          │      авторизации │  пароль вашего прокси    │
└─────────────────────────┘                  └────────────┬────────────┘
                                                          │ через ваш прокси
                                                          ▼
                                          ┌───────────────────────────┐
                                          │  Зарубежный прокси         │
                                          │  (HTTP или SOCKS5)         │  ──▶  api.anthropic.com
                                          └───────────────────────────┘
```

Приложение само поднимает мост, прописывает нужные настройки и следит, чтобы
всё работало. Через прокси идёт **только** трафик Claude — остальной интернет
не затрагивается.

## 📥 Установка

Понадобится строка вашего **купленного зарубежного прокси** в формате
`http://логин:пароль@адрес:порт` или `socks5://логин:пароль@адрес:порт`.
Тип (HTTP/SOCKS5) программа определит сама.

### 🖥️ Windows 10 / 11 (64-бит)

1. Скачайте `Claude-Proxy-Tunnel_*_x64-setup.exe` из
   [**последнего релиза**](../../releases/latest).
2. Правый клик по файлу → **Свойства** → галочка **«Разблокировать»** → OK.
3. Запустите. Если появится SmartScreen — «Подробнее» → «Выполнить в любом случае».
4. Пройдите мастер: вставьте строку прокси, остальное программа сделает сама.

### 🍎 macOS (Apple Silicon — M1/M2/M3…)

1. Скачайте `Claude-Proxy-Tunnel_*_aarch64.dmg` из
   [**последнего релиза**](../../releases/latest).
2. Откройте `.dmg` и перетащите приложение в папку «Программы».
3. Первый запуск: **правый клик по приложению → «Открыть» → подтвердите**
   (приложение собрано без сертификата Apple — для своей сборки это нормально,
   достаточно подтвердить один раз).
4. Пройдите мастер: вставьте строку прокси.

## ⬆️ Обновления

Внутри программы: **Настройки → Обновления → Проверить обновления**. Если есть
новая версия — кнопка «Обновить» сама всё скачает, установит и перезапустит
приложение. Либо просто скачайте свежий установщик из
[Releases](../../releases/latest).

---

## 🧹 Удаление

В приложении: **Настройки → Удаление → «Полностью удалить программу»**.
Мастер уберёт всё, что поставила программа (мост, автозапуск, настройки,
переменные окружения, Claude Code CLI), и предложит галочками удалить
сопутствующее — Claude Desktop и Node.js (по умолчанию выключено). Системные
компоненты (например, Python в составе macOS) не трогаются.

---

## 🩺 Если что-то не работает

| Симптом | Что делать |
|---|---|
| Иконка в трее **жёлтая** | Откройте приложение → кнопка «Восстановить» |
| Иконка **красная** | Настройки → «Запустить шим» |
| Claude пишет «socket closed» | Откройте приложение: если статус зелёный — перезапустите Claude; иначе действуйте по иконке выше |
| Прокси не проходит проверку | Проверьте в личном кабинете продавца: привязку по IP, срок аренды, логин/пароль |

---

## 🔒 Приватность

- Через прокси идёт **только** трафик Claude — остальные программы и сайты
  работают напрямую.
- Мост не добавляет заголовков, раскрывающих ваш реальный IP — для Anthropic
  виден только IP вашего прокси.
- Прокси вы покупаете и вводите сами; в установщике никаких чужих учётных
  данных нет. Ваши данные хранятся локально, на вашем компьютере.

⚠️ Использование прокси для обхода географических ограничений может нарушать
условия сервисов. Используйте на свой риск.
