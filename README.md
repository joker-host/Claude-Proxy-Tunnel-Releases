## 💡 Зачем это нужно

Anthropic API (`api.anthropic.com`) не отвечает из некоторых стран, включая
Россию. Выход — пустить трафик Claude через зарубежный прокси. Вручную это
неудобно и быстро ломается:

- **Claude Desktop и VS Code** не умеют ходить через прокси с логином и
  паролем: показывают окно авторизации или молча отваливаются.
- **Длинные ответы Claude** (фаза «размышления», минуты тишины) обрываются с
  ошибкой `socket connection was closed unexpectedly`.
- После перезагрузки настройка слетает, и Claude перестаёт работать.

Claude-Proxy-Tunnel закрывает это за пару минут и держит рабочим дальше.

## ✨ Что умеет

| Возможность | Что делает |
|---|---|
| 🌉 **Локальный мост** | Подставляет логин и пароль вашего прокси за приложения — им не нужно знать про авторизацию |
| 🔌 **HTTP и SOCKS5** | Понимает оба типа; определяет нужный сам по строке прокси |
| ⚡ **Без лишней задержки** | Держит соединение живым (TCP_NODELAY + keep-alive): запросы идут быстро, длинные ответы не обрываются |
| 🔁 **Переживает перезагрузку** | При входе в систему мост и переменные поднимаются сами — Claude работает сразу |
| 🟢 **Статус в трее** | Зелёный (всё работает) / жёлтый (нужно внимание) / красный (мост остановлен) |
| ⬆️ **Обновление из приложения** | Настройки → Обновления → одна кнопка скачает и поставит новую версию |
| 🧹 **Чистое удаление** | Мастер убирает всё, что поставила программа; сопутствующее — по галочкам |
| 🛡️ **Защита брандмауэром** | *(только Windows)* мост может ходить **только** на ваш прокси и никуда больше — на уровне ОС |

## 🧭 Как это работает

```
┌─────────────────────────┐                  ┌─────────────────────────┐
│  Claude Code (VS Code)  │   локально, без  │  Мост на 127.0.0.1:8889 │
│  Claude Code в терминале │  ───────────────▶│  подставляет логин/     │
│  Claude Desktop          │      авторизации │  пароль вашего прокси    │
└─────────────────────────┘                  └────────────┬────────────┘
                                                          │ через ваш прокси
                                                          ▼
                                          ┌───────────────────────────┐
                                          │  Зарубежный прокси         │
                                          │  (HTTP или SOCKS5)         │  ──▶  api.anthropic.com
                                          └───────────────────────────┘
```

Приложение поднимает мост, прописывает настройки и держит их рабочими. Через
прокси идёт только трафик Claude; остальной интернет не затрагивается.

## 📥 Установка

Понадобится строка вашего зарубежного прокси: `http://логин:пароль@адрес:порт`
или `socks5://логин:пароль@адрес:порт`. Тип (HTTP или SOCKS5) программа
определит сама.

### 🖥️ Windows 10 / 11 (64-бит)

1. Скачайте `Claude-Proxy-Tunnel_*_x64-setup.exe` из
   [**последнего релиза**](../../releases/latest).
2. Правый клик по файлу → **Свойства** → галочка **«Разблокировать»** → OK.
3. Запустите. Если появится SmartScreen — «Подробнее» → «Выполнить в любом случае».
4. Вставьте в мастере строку прокси — дальше программа сделает всё сама.

### 🍎 macOS (Apple Silicon — M1 и новее)

> **Нужен Mac на Apple Silicon: M1, M2, M3, M4 и новее.**
> Система — macOS 11 Big Sur или новее.
> На Mac с процессором Intel программа не поддерживается.
>
> Какой у вас процессор: меню Apple → «Об этом Mac» → строка «Чип».
> Если там написано «Процессор Intel» — программа не подойдёт.

**1. Скачайте** образ кнопкой **«Скачать для macOS»** выше — файл
`Claude-Proxy-Tunnel-macOS.dmg` появится в папке **«Загрузки»**.

**2. Установите в «Программы»:**
- дважды кликните по скачанному `.dmg` — откроется окно;
- **перетащите значок приложения на папку «Программы»** в этом же окне;
- закройте окно; в Finder слева рядом с «диском» Claude-Proxy-Tunnel нажмите
  **⏏ (извлечь)**, чтобы убрать образ.

> ⚠️ Запускайте приложение **из папки «Программы»**, а не из открытого окна `.dmg` —
> иначе macOS не даст его открыть.

**3. Первый запуск — разрешите открытие (нужно один раз).**
При первом запуске macOS покажет окно «Apple не удалось подтвердить…». Программа
бесплатная и не подписана платным сертификатом Apple ($99/год), поэтому система
перестраховывается. Разблокируйте любым способом:

**Способ А — без Терминала:**
1. Дважды кликните по приложению → в появившемся окне нажмите **«Готово»**
   (НЕ «Переместить в Корзину»).
2. Откройте **Системные настройки → «Конфиденциальность и безопасность»**.
3. Прокрутите вниз до строки про «Claude-Proxy-Tunnel» → нажмите
   **«Открыть всё равно»** → подтвердите паролем или Touch ID.

**Способ Б — одной командой (быстрее):**
Откройте **Терминал** (Программы → Утилиты → Терминал) и вставьте:
```
xattr -cr /Applications/Claude-Proxy-Tunnel.app
```
После этого приложение открывается обычным двойным кликом.

**4. Вставьте в мастере строку прокси** — дальше программа сделает всё сама.

> 💡 Разрешение нужно **только при первом запуске**. Дальнейшие запуски и
> обновления внутри программы (Настройки → Обновления) идут без предупреждений.

## ⬆️ Обновления

Внутри программы: **Настройки → Обновления → Проверить обновления**. Если вышла
новая версия — кнопка «Обновить» сама скачает её, поставит и перезапустит
приложение. Либо скачайте свежий установщик из
[Releases](../../releases/latest).

---

## 🧹 Удаление

В приложении: **Настройки → Удаление → «Полностью удалить программу»**. Мастер
уберёт всё, что поставила программа (мост, автозапуск, настройки, переменные
окружения, Claude Code CLI), и предложит галочками снести сопутствующее —
Claude Desktop и Node.js (по умолчанию выключено). Системные компоненты
(например, Python в составе macOS) не трогаются.

## 🩺 Если что-то не работает

| Симптом | Что делать |
|---|---|
| Иконка в трее **жёлтая** | Откройте приложение → кнопка «Восстановить» |
| Иконка **красная** | Настройки → «Запустить шим» |
| Claude пишет «socket closed» | Откройте приложение: если статус зелёный — перезапустите Claude; иначе действуйте по иконке выше |
| Прокси не проходит проверку | Проверьте в личном кабинете продавца: привязку по IP, срок аренды, логин и пароль |

## 🔒 Приватность

- Через прокси идёт **только** трафик Claude; остальные программы и сайты ходят
  напрямую.
- Мост не добавляет заголовков с вашим реальным IP — для Anthropic виден только
  IP прокси.
- Прокси вы покупаете и вводите сами; чужих учётных данных в установщике нет.
  Данные хранятся локально, на вашем компьютере.

⚠️ Прокси для обхода географических ограничений может нарушать условия сервисов.
Используйте на свой риск.
