# Claude-Proxy-Tunnel

Десктопная утилита для **Windows**, которая позволяет пользоваться **Claude Code** (в терминале и в VS Code) и **Claude Desktop** в регионах, где API Anthropic недоступен напрямую — весь трафик Claude идёт через ваш зарубежный HTTP-прокси, а остальной интернет не затрагивается.

> Это репозиторий **только с релизами** (установщик + манифест обновлений). Исходный код — в приватном репозитории.

## Что делает

- Поднимает локальный мост на `127.0.0.1:8889`, который добавляет авторизацию к вашему прокси (Electron-приложения сами этого не умеют).
- Настраивает Claude Code (CLI и расширение VS Code) и Claude Desktop на работу через этот мост.
- Защищает мост правилами Windows Firewall: он может ходить только на ваш прокси и никуда больше.
- Сам восстанавливает настройку после перезагрузки и обновлений (heal-on-boot).
- Показывает в трее состояние: всё работает / проблема / мост остановлен.
- Обновляется прямо из интерфейса (Настройки → Обновления).

## Установка

1. Скачайте последний установщик из раздела [**Releases**](../../releases/latest) — файл `Claude-Proxy-Tunnel_x.y.z_x64-setup.exe`.
2. Запустите его и пройдите мастер. Понадобится строка вашего **купленного зарубежного HTTP-прокси** в формате `http://логин:пароль@адрес:порт`.
3. Мастер сам поставит нужные компоненты и настроит прокси.

Требуется Windows 10/11 (x64).

## Обновления

Внутри программы: **Настройки → Обновления → Проверить обновления**. Если доступна новая версия — кнопка «Обновить» сама всё скачает, установит и перезапустит приложение. Либо просто скачайте новый установщик из Releases.

## Приватность

- Через прокси идёт только трафик Claude — остальные программы и сайты работают напрямую.
- Мост не добавляет никаких заголовков, раскрывающих ваш реальный IP.
- Прокси-доступ вы покупаете и вводите сами; в установщике никаких учётных данных не зашито.
